# 接入与验证边界

## 源码与交付范围

升级基线为E:/xiugai/srctianjia，而不是无法找到的实物最新源码。原始关键文件只读副本在reference/*.txt；外部文件SHA256在reference/outside_before.json。未反编译vvp恢复源码，未改原工程的任何.gprj、CST或声音逻辑。

本目录的visual_demo.gprj专门测试视频输出：50MHz输入、原复位脚K16、J11差分输出；内部DDS逐样本产生测试波形，不播放录音，也不接原电子琴的DAC。它不能代替完整钢琴固件。真实接入时只添加需要的显示模块，不加入visual_test_top。

## X/Y输入语义

- `xy_enable=1`：外部保证xy_x/xy_y是两路真实声部，并在pcm_valid沿同拍稳定。本模块保留两轴比例，共同去直流/缩放；不同频率、谐波和包络会形成复杂真实图形。两个不成简单整数比的声部不保证闭合图形。
- `xy_enable=0`：观察PCM经Hilbert滤波得到的解析相图。X为同一PCM延迟31样本，Y为63tap Hamming窗Hilbert FIR；32个非零系数共用MAC。不生成装饰用正弦，不反馈给声音。
- 波形通道仍观察最终PCM。Hilbert分支X/Y相对它有31样本群延迟（48kHz约0.646ms）；这仅是显示分析延迟，不是音频发声延迟。
- FIR输出至少64次有效采样后才有效。busy期间过快输入只增加内部overruns，不反压音频；设计默认每256个音频时钟一个采样，32tap计算可在间隔内完成。过快输入不用于证明有效音频分析。
- 位宽使用PCM/声部的[23:8]，保留16位。如果上游已经把信号截为零，本模块不能恢复丢失的信息。
- 每帧512组样本计算各轴均值，再以两轴共同绝对峰值选择一个二进制移位量，映射到128×128正方形。图形按整数3倍显示。X/Y缩放是显示增益，不是声部增益，不用于读取绝对幅度。
- `XY AUTO 2^±nn`表示原始16位去直流样本到坐标偏移的二进制比例；与PCM满量程刻度不同。不能把自动缩放后的图形大小直接解读为演奏响度。
- 去直流后共同峰值小于8个16位LSB时显示NO SIGNAL，避免放大极低电平噪声。混合了两种X/Y来源的快照清空并显示SOURCE CHANGED，下一完整同源帧恢复。
- 有限阶Hilbert滤波低频端存在幅度误差，近Nyquist又受48kHz采样限制。高音可能呈多边形、直线或稀疏轨迹，不能承诺所有音高都为圆；≥24kHz不可能由48kHz采样正确展示。

## 图像与视频时序

默认LOGN11的FFT算法、37位功率及自然序bin未改；频谱保留线性0～约24kHz、log2功率近似柱高，不冒充标定dBFS或自动基频识别。

扫描：H有效1920，前沿88，同步44，后沿148，总2200；V有效1080，前沿4，同步5，后沿36，总1125；HS/VS正极性。74.25MHz/(2200×1125)=30Hz。默认不是1080p60或隔行1080i。

GW5AST数据手册要求PFD19～81.25MHz、VCO650～1300MHz。50MHz直接尝试1485MHz VCO不合规；本版改用两级视频PLL：

1. 50/2×27=675MHz VCO，ODIV0=25，得到27MHz参考。
2. 27×27.5=742.5MHz VCO，ODIV0=2得到371.25MHz串行，ODIV1=10得到74.25MHz像素。

MDIV_FRAC_SEL4表示0.5，两个输出分频均为整数，pixel/serial保持1:5。原PLL_INIT适配器分别使用输入时钟周期20ns/约37ns与对应反馈倍率参数；这只是参数准备和数学/接口验证，仍需Gowin原语库、PLL/IP配置及实际锁定验证，不能将仿真接口stub当真实PLL。

音频域与像素域使用冻结快照CDC；共同异步复位断言、分别同步释放。重绘只在垂直消隐期触发：128×128位图清空、两遍扫描、Bresenham最多约6.6万步、频谱复制，设计预算小于45×2200=99000像素时钟。测试覆盖高频大跨度连线。无新快照不再清除旧图。显存和读端无RAM异步复位，支持工具推断块存储。

约束文件给出精确时钟比，节点名以本包demo层次为准；实际钢琴顶层必须改实例路径，避免重复create_clock或错误的set_clock_groups。视频掉锁不会被串入原音频复位条件。

## 已有检查能证明什么

脚本检查X/Y逐样本整数模型、1kHz～22kHz正交相关性/幅度、极低电平、正方形/椭圆/同相信号、DC/静音、来源切换、连续线段及消隐预算；检查音频域采样到CDC冻结帧的同拍关系、双域复位、1024/2048/4096点FFT黄金值、1080扫描几何和TMDS编码。

PNG来自真实renderer RTL在640×360逻辑网格的输出，并以整数最近邻3倍重建；另外抽检3×3子像素完全一致。完整2200×1125扫描由独立raster测试覆盖。图中输入为测试数据，不是实物琴键的测量画面。

不能证明：照片所用未知版本的具体根因已经定位；与当前实际钢琴顶层无冲突；Gowin P&R、显示器EDID/兼容性、物理OSER10/HDMI线路、PLL锁定或最终音频质量。未提供“已通过实物验证”的固件。
