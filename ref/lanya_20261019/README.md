# ESP32 Wi-Fi 乐器控制

所有代码只在本目录，原JDY方案已移除。手机连接ESP32热点，网页通过双向UART控制FPGA；主钢琴、显示和特雷门工程没有改动，也没有烧录。

## 本轮新增：双链路、默认值和32键配置（2026-10-19）

- 顶部拆为手机↔ESP32与ESP32↔FPGA两条状态。收到HTTP响应表示ESP32可访问；只有有效协议应答才确认UART连接。FPGA拒绝操作或乐器故障不等于UART断开。请求期间显示等待应答，超时后标明通信异常；手机无法访问ESP32时，FPGA状态显示未知。
- 音量和速度分别增加恢复默认值：100%、120 BPM。走正常UART设置与实际值回读，不只重置页面滑条。
- 主页面“键位自定义”打开 `/keymap`。两块琴各16键，共32项；支持半音阶、C大调、C宫五声音阶、起始八度、16键预览及单键修改。
- 编辑与恢复默认仅改变草稿；“应用到FPGA”提交完整32项，随后核对提交版本与全部映射。重新读取会先提示丢弃未应用草稿。页面切换丢失未提交草稿；已提交配置保存在FPGA RAM，断电恢复默认。
- 默认第一块K1..K16=MIDI60..75，第二块=MIDI72..87，均为半音阶。C4=MIDI60；两块音域可重叠。预设必须让全部16键处于MIDI36..96，超范围拒绝，不自动截断。
- 新增32键接口需要FPGA配套升级。旧16键固件无法通过05能力/元数据查询，页面不会将其当作32键配置成功。

**队友主工程必接内容见 [FPGA接入说明](kongzhi/README.md#32键映射的主工程改动由队友完成)。本包只接通网页、ESP32和独立FPGA模块，不修改主工程，不宣称实体琴键已按新映射发声。**

## 手机上新增的功能

- **音量滑条：0～100%**。FPGA对最终PCM做平滑音量缩放；页面读回实际增益，不只回显请求值。
- **速度滑条：30～240 BPM**。改变曲谱播放时间，不改音高，不改变手动弹琴节奏。播放中也能调。
- **曲谱下载和导入**：输入HTTPS文件直链在线下载MIDI或音符JSON，也可以选手机里的文件。预览后选择音轨、分段，再传给FPGA；有播放和停止按钮。
- 保留5种音色、琴键/特雷门/合奏切换及实际状态查询。

拖动滑条时合并过时请求，保留最后一次设置。曲谱先暂存、完整后提交，失败不破坏原曲谱；提交后核对FPGA返回的数量和版本号。

## 怎么使用

1. Arduino IDE打开 `esp32/ESP32_FPGA_Music_Controller/ESP32_FPGA_Music_Controller.ino`。选实际ESP32-S3开发板和Flash/PSRAM设置。
2. 手机连 `FPGA_MUSIC`，密码 `fpga2026`，打开 `http://192.168.4.1`。
3. 在线下载时，展开“在线下载的联网设置”，让ESP32连接能上网的2.4GHz Wi-Fi，点击“检查联网状态”。等待联网及校时完成后输入文件直链。公开解析测试文件可参考 [MIDI测试直链](https://raw.githubusercontent.com/Tonejs/Midi/master/test/midi/pitchBendTest.mid)（只验证下载和解析，不导入弯音）。手机继续连控制热点；Wi-Fi切换信道时若掉线，重新连接即可。Wi-Fi密码不写入代码或持久存储。
4. 也可从手机导入文件，无需互联网。示例在 `shouji/examples/twinkle.json`，可以先用它验证音符数据。
5. 选择MIDI单旋律音轨和分段，点“传给FPGA”，确认成功后播放。导入时BPM会作为该曲谱建议速度设置；随后可以拖动速度滑条调整。

**FPGA接口已扩展，接入必须同步升级。** 推荐入口 `wifi_remote_control.sv`。除旧的模式/音色反馈，还要接最终PCM输入与缩放后的PCM输出、48kHz采样使能、曲谱音符事件握手以及允许开始播放的安全条件。具体见 `kongzhi/README.md`。仅烧录ESP32、未接FPGA代码时，网页会显示未确认。

## 曲谱支持范围

- 文件最多64KB；MIDI支持格式0/1、PPQN拍点计时，按音轨及通道选择。当前支持单旋律，和弦/重叠音符会提示改选音轨，不会悄悄丢音。
- 当前音源音域MIDI36～96。不导入踏板、弯音、音色指令和文件中途变速；统一由BPM滑条控制速度。
- 每段最多32个事件（包括休止），长曲明确分段，手动选择一段传入和播放；不会自动连续播放所有分段。
- JSON格式见示例：`name`、`bpm`、`events`；事件为`[MIDI音符,力度,基准时长]`，力度0是休止。基准时长是在120 BPM下的毫秒数，四分音符写500。
- HTTPS要求文件直链，不是曲谱网站页面；需公开访问且无需登录或跳转。下载校验证书，不会自动上传到FPGA；确认前只用于预览。
- 曲谱存在FPGA RAM，掉电丢失。断开手机不会自动停止已经开始的曲谱；停止靠播放器或页面停止按钮。

## 接线

两端115200、8N1，3.3V UART，分别供电、共地。

| ESP32 | FPGA |
|---|---|
| GPIO17 TX → | B19 / J26第7脚，wifi_uart_rx |
| GPIO18 RX ← | A17 / J26第5脚，wifi_uart_tx |
| GND ↔ | GND / J26第3或4脚，仍需按实物丝印确认 |

此分配与下载目录旧测试程序注释中的J22、L22/M26不同；按本目录 `yinjiao/wifi_pins.cst` 成套使用，核对底板型号与Bank 3.3V供电。

## 自动查询与断连显示

自动查询为静默后台操作，不禁用其他按钮、不显示等待动画，不重写未变化的控件和提示。正常时每次查询完成后约1.5秒再查，未连接/异常时约10秒再尝试，页面隐藏时暂停自动请求。断连或恢复只更新一次相应状态；滑条和本地曲谱预览保留。手动刷新及控制操作仍有正常等待与结果反馈，后台查询期间的手动控制会排队执行。

## 毛玻璃配色与底栏导航

以用户参考图的深蓝、青蓝、雾紫和淡粉为配色，使用静态大面积渐变、半透明卡片、backdrop-filter与-webkit-backdrop-filter实现毛玻璃。按压会有下沉、高光和蓝色反射变化，持续高亮表示本地选择，“已应用”仅在设备实际回读一致时显示；系统减少动态效果时关闭过渡。不支持毛玻璃的浏览器使用较实的半透明底色。

底栏为控制/键位/曲谱/设置，已移除顶部键位配置入口。控制、曲谱、设置在同一页面通过hash切换可见面板，保留曲谱预览及输入，不重新建立UART请求器；键位仍使用原独立页面，离开有未应用修改时保留确认。设置包含联网设置和调试信息；没有新增不工作的占位页。键位应用栏位于导航上方，已为两个固定栏与安全区预留底部滚动空间。资源全部由ESP32本地提供，无外部框架/CDN，未修改FPGA接口。

## 响应与紧凑布局精修

音色/演奏模式点击立即保持蓝色高亮，设备回读一致且未切换/故障时才标记“已应用”。断连失败仍保留本地选择并显示“未应用”；快速连点时同类待发送设置合并为最后一次。页面字号、卡片、按钮和底栏缩小，声音控制使用图标、数值、发光滑条及速度加减，保留各自恢复默认按钮。两块琴标题均为普通文字，K16采用深蓝底白字。

键位页一进入即提供默认32键草稿，无FPGA也可选择、保存单键、使用预设；底栏仅显示本地配置/未应用数量/已应用。读取与应用期间可继续编辑，晚到回读不会覆盖之后的新修改；设备连接后才允许应用。页面草稿未持久化，离开有修改时仍提示确认。
