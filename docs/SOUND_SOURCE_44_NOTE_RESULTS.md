## 衰减和定点归零

44音自然归零范围 2.523～11.620s（模型）。没有不能起音或2秒内整音突然归零的证据，但高音包络/门限的退出行为仍需区分正常衰减与尾段被舍弃。T20/T40为10ms RMS相对峰值最后越过阈值的时刻，QUANTIZATION.csv给出；NOTE_METRICS_44.csv同时给出从RMS峰值算起的衰减时长，不冒称室内声学混响时间。

实际算术为 unsigned18 exp → shift/offset1049 → gate≤1153 → unsigned24 amplitude × signed18 wave → signed45 product → signed48累加 >>>18 → 24bit饱和；Q15主增益32767 >>>15；FX保留其定点状态和限幅。所有44音新的Voice RTL与模型一致。选取48/64/79/84/91的实际内部操作数逐记录核对exp、门限、符号乘法；长按模型记录所有44音的亚LSB乘积、正小和归零、负小和算术右移到−1、最大乘积/累加值及门限样本。

QUANTIZATION.csv 的 sub-LSB 计数不是音符丢失数。单个零交叉、小于1LSB和自然包络结束都可能给零；未发现溢出或错误位宽造成整音立即消失。长期归零主要由现有partial门限和Voice退出条件决定。PT8211丢低8位与PCM5102保留24位的差别也单列；这种量化不解释C6在FX前已出现的20多dB响度落差。
