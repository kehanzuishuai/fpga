# 手机控制页面

页面由 ESP32 同源提供，无需另建网站。主页面 `index.html/app.js`，32 键配置 `keymap.html/keymap.js`，`device-api.js` 处理异步设备任务，`score.js` 解析曲谱及合并复调时间线。

## 整曲多轨播放

选择“自动演奏” → 导入 MIDI → 选择“全部旋律音轨（不含打击乐）” → 点击“传入设备” → 等待“整曲已缓存，点击播放” → 播放。

- 文件上限 65,536 字节；MIDI 格式 0/1、PPQN 计时、最多 64 轨。
- 多轨自动播放合并为最多 32 个同时不同音高、32,768 个起音/松音事件；音域 MIDI 36～96。
- JSON 是顺序单旋律格式，每项 `[note, velocity, duration_ms]`，时长基于 120 BPM；最多 4096 项。多轨《卡农》请导入 `.mid` 文件。
- 所有音轨使用统一 BPM 和 FPGA 当前音色；中途变速、踏板、弯音、程序音色指令不导入。
- 同音高重叠使用引用计数，全部释放才发送松音；同一时刻重触发先松后按。

指导模式使用所选单旋律轨的 32 项分段，不接收和弦重叠。切换到指导模式后需重新选择并传入对应分段。

“导入”只读取手机文件；“传入设备”才提交到设备。最新页面明确提示此区别，并按真实播放回读确认开始/停止。修改任意网页资源后运行 [build_web.py](../esp32/build_web.py)，重新编译、烧录 ESP32 并刷新手机页面。

示例：[最新多音轨卡农](../../../scores/卡农_最新ESP32_20261103/)、[twinkle.json](examples/twinkle.json)。
